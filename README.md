# Калькулятор матриц комплексных чисел

Практическая работа по курсу «Программирование на языке Java».

Консольное приложение для работы с матрицами комплексных чисел: сложение,
умножение, деление, транспонирование и вычисление определителя.

## Возможности

- Сложение двух матриц (`A + B`)
- Умножение двух матриц (`A * B`)
- Деление матриц как `A * B⁻¹`
- Транспонирование матрицы (`Aᵀ`)
- Вычисление определителя методом Гаусса с выбором главного элемента
- Сохранение последнего результата и его повторное использование как `A` или `B`
- Обработка ошибок: несовпадение размеров, деление на вырожденную матрицу,
  деление на нулевое комплексное число, некорректный ввод

## Структура проекта

```
complex-matrix/
└── src/
    ├── Complex.java         — неизменяемое комплексное число
    ├── ComplexMatrix.java   — матрица и операции над ней
    └── Main.java            — консольный интерфейс
```

### `Complex`

Неизменяемый класс (`private final` поля, `equals`/`hashCode` согласованы
через точность `EPS = 1e-9`).

Основные методы:

| Метод | Назначение |
|---|---|
| `plus(Complex)`, `minus(Complex)` | Сложение и вычитание |
| `multiply(Complex)` | Умножение |
| `divide(Complex)` | Деление (кидает `ArithmeticException` при делении на ноль) |
| `abs()` | Модуль комплексного числа |
| `isZero()` | Проверка на ноль |

### `ComplexMatrix`

Хранит матрицу как `Complex[][]`, все операции возвращают новую матрицу,
исходные данные не изменяются.

| Метод | Назначение |
|---|---|
| `add(ComplexMatrix)` | Поэлементное сложение |
| `multiply(ComplexMatrix)` | Матричное умножение |
| `divide(ComplexMatrix)` | `A * B⁻¹` |
| `transpose()` | Транспонирование |
| `determinant()` | Определитель |
| `inverse()` | Обратная матрица (Гаусс–Жордан) |
| `get`, `set` | Доступ к элементам |

### `Main`

Меню с шестью операциями и отдельным пунктом для просмотра сохранённого
результата. Если результат уже есть, при вводе новой матрицы `A` или `B`
предлагается использовать его повторно.


## Сборка и запуск


```bash
javac -encoding UTF-8 -d out src/*.java
java -cp out Main
```

## Формат ввода

**Комплексное число** — одно или два числа через пробел:

```
3 -2      ->  3 - 2i
5         ->  5 + 0i
0 1       ->  0 + 1i
```

Разделителем может быть пробел или табуляция. Десятичный разделитель —
точка или запятая (`3,5` и `3.5` эквивалентны).

**Размеры матрицы** — целые числа от 1 до 10.

## Пример работы

```
=== КАЛЬКУЛЯТОР МАТРИЦ КОМПЛЕКСНЫХ ЧИСЕЛ ===
Элемент матрицы: два числа через пробел (действительная и мнимая части).
Если мнимой части нет, можно ввести одно число: 5  ->  5 + 0i.

---------------------------------------------
1. Сложить две матрицы        A + B
2. Перемножить две матрицы    A * B
3. Разделить две матрицы      A / B = A * B^(-1)
4. Транспонировать матрицу    A^T
5. Вычислить определитель     det A
6. Показать сохранённый результат
0. Выход
---------------------------------------------
Ваш выбор: 1

--- Ввод матрицы A ---
  Строк (1..10): 2
  Столбцов (1..10): 2
  Формат элемента: <re> <im>  (например: 3 -2  или  5)
  [0][0] = 1 2
  [0][1] = 3
  [1][0] = 0 -1
  [1][1] = 4 1
--- Ввод матрицы B ---
  Строк (1..10): 2
  Столбцов (1..10): 2
  [0][0] = 1
  [0][1] = 0
  [1][0] = 2 1
  [1][1] = -1

Результат (сохранён для следующих операций):
[ 2+2i   3-2i ]

Ваш выбор: 5

[ 2+2i   3-2i ]
[  2     3+1i ]
Взять его как матрицу A? (1 — да, 2 — ввести новую): 1
```

## Реализованные алгоритмы

- **Определитель** — метод Гаусса с выбором ведущего элемента по столбцу
  (наибольший модуль). Сложность `O(n³)`.
- **Обратная матрица** — метод Гаусса–Жордана с расширенной матрицей
  `[A | E]`, приведением левой части к единичной. Сложность `O(n³)`.
- **Деление** `A / B` — через `A * B⁻¹`.

## Обработка ошибок

Все ошибки выводятся в консоль и не приводят к аварийному завершению
программы:

| Ситуация | Сообщение |
|---|---|
| Размеры не совпадают при сложении | `Сложение требует одинаковых размеров: ...` |
| Число столбцов `A` ≠ число строк `B` | `Умножение невозможно: ...` |
| Делитель не квадратный | `Деление возможно только на квадратную матрицу` |
| Вырожденная матрица | `Матрица вырождена (определитель = 0), обратной не существует` |
| Деление на `0 + 0i` | `Деление на ноль (нулевой комплексный делитель)` |
| Определитель не квадратной матрицы | `Определитель определён только для квадратной матрицы` |
| Ввод не-числа | `Ожидалось целое число. Попробуйте ещё раз.` |
